# Semga67 — лабораторная работа №3

Проект по структурам данных для запросов на отрезках (RSQ / RMQ) с замером сложности через **подсчёт ключевых операций**, а не через таймер.

Целевой уровень реализации: **до 8 баллов** (без гибрида sqrt+sparse и без графиков по времени с `-O3`).

## Структуры (план)

| Уровень | Структуры |
|---------|-----------|
| 4 | 1D/2D prefix sum (RSQ), предпосчитанный RMQ — **готово** |
| 6 | Корневая декомпозиция (RSQ, RMQ), дерево отрезков (RSQ) — **готово** |
| 8 | Дерево Фенвика (RSQ), разреженная таблица (RMQ) — **готово** |

## Требования

- Компилятор с поддержкой **C++20**
- **CMake** 3.20+
- Для графиков (после benchmark): **Python 3** и зависимости из `scripts/requirements.txt`

## Сборка

```bash
cmake -S . -B build
cmake --build build
```

Исполняемый файл: `build/semga67_cli`

## Запуск

```bash
./build/semga67_cli --help
./build/semga67_cli self-test
./build/semga67_cli verify
./build/semga67_cli benchmark
```

| Команда | Описание |
|---------|----------|
| `--help` | Справка |
| `self-test` | Проверка инфраструктуры (счётчик операций) |
| `verify` | Корректность реализованных структур |
| `benchmark` | Замеры ключевых операций и запись CSV в `results/` |

## Сложность структур уровня 4

| Структура | Построение | Запрос | Ключевая операция (build) | Ключевая операция (query) |
|-----------|------------|--------|---------------------------|---------------------------|
| `PrefixSum1D` | O(n) | O(1) | 1 сложение на элемент | 1 вычитание префиксов |
| `PrefixSum2D` | O(n·m) | O(1) | 3 операции на ячейку | 4 операции вкл.-искл. |
| `PrecomputedRMQ` | O(n²) | O(1) | 1 сравнение на расширение отрезка | 1 обращение к таблице |

## Сложность корневой декомпозиции (Milestone 2)

| Вариант | Построение | Запрос | Combine при build | Combine при query |
|---------|------------|--------|-------------------|-------------------|
| `SqrtDecomposition` (RSQ) | O(n) | O(√n) | 1 на элемент | 1 на каждый merge в ответ |
| `SqrtDecomposition` (RMQ) | O(n) | O(√n) | 1 `min` на элемент | 1 `min` на каждый merge |

Универсальный каркас: `SqrtDecomposition<T, Combine>`; фабрики `make_sqrt_rsq`, `make_sqrt_rmq` передают операцию через лямбду.

## Сложность дерева отрезков для RSQ (Milestone 3)

| Операция | Сложность | Ключевая операция |
|----------|-----------|-------------------|
| Построение | O(n) | 1 сложение на каждый внутренний узел (`n - 1` всего) |
| `query(l, r)` | O(log n) | 1 сложение на каждое слияние двух частичных ответов |
| `update(i, v)` | O(log n) | 1 сложение на каждом уровне при пересчёте предка |

Класс: `SegmentTreeRsq` — `query(l, r)`, `update(index, value)`.

## Сложность уровня 8 (Milestone 4)

### `FenwickTreeRsq`

| Операция | Сложность | Ключевая операция |
|----------|-----------|-------------------|
| Построение | O(n) | 1 сложение на каждую связь `i → i + lowbit(i)` |
| `query(l, r)` | O(log n) | 1 сложение на шаг префикса + 1 вычитание |
| `update(i, v)` | O(log n) | 1 сложение дельты на шаг вверх по дереву |

### `SparseTableRmq`

| Операция | Сложность | Ключевая операция |
|----------|-----------|-------------------|
| Предобработка | O(n log n) | 1 `min` на ячейку уровня `k > 0` |
| `query(l, r)` | O(1) | 1 сравнение двух перекрывающихся отрезков |
| Обновление | — | не поддерживается |

## Benchmark (Milestone 5)

Замеры выполняются **только по счётчику операций**, без измерения времени.

### Запуск

```bash
./build/semga67_cli benchmark
```

Параметры по умолчанию (в `src/benchmark.cpp`):

| Параметр | Значение |
|----------|----------|
| Запросов на размер | 10 000 |
| Обновлений на размер | 1 000 |
| Seed | 42 |

**Сетки размеров:**

- 1D (большинство структур): `n ∈ {100, 200, 500, 1000, 2000, 5000, 10000, 20000, 50000}`
- `precomputed_rmq`: `n ∈ {50, 100, 200, 500, 1000, 2000}`
- 2D `prefix_sum_2d`: `n = m ∈ {10, 20, 50, 100, 200, 500}`

### Файлы результатов

| Файл | Содержимое |
|------|------------|
| `results/benchmark_1d.csv` | Все одномерные структуры |
| `results/benchmark_2d.csv` | 2D prefix sum |

CSV **не коммитятся** (см. `.gitignore`).
